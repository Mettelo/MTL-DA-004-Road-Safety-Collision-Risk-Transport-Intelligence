# Project Governance

## Project Classification

Mettelo Project Studio — simulated confidential-client engagement.

## Client Representation

The confidential client is simulated.

Participants must not claim:

- employment by the simulated client;
- access to a real confidential transport authority;
- that STATS19 is private Mettelo client data;
- that Mettelo has an undisclosed external client relationship represented by this project.

Participants may accurately describe verified participation in Mettelo Project Studio.

## Data Source

The underlying dataset is official Department for Transport road-safety open data collected through the STATS19 reporting system.

Teams must retain appropriate source attribution and follow the Open Government Licence requirements.

## Responsible Analytics

Teams must:

- avoid unsupported causal claims;
- acknowledge under-reporting and coverage limitations;
- distinguish counts from risk/exposure rates;
- document denominator limitations;
- avoid identifying individuals;
- use geography responsibly;
- avoid stigmatising areas or road-user groups;
- document uncertainty and changes in data collection.

## GitHub Security

Never commit:
- passwords;
- tokens;
- API keys;
- private credentials;
- personal data not intended for publication.

## Verification

Mettelo may review commits, issues, pull requests, reviews, documents, code, analytical artefacts and presentation evidence to verify participation and contribution.
